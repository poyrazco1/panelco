# Asset Licenses

Per `docs/SOURCE_3D_CONVERSION_PROMPT.md` §17, every asset sourced from
outside this project must be recorded here with its source URL,
license, author, any modification made, and the usage terms. **No
external audio, texture, or model assets have been downloaded or used
in this project yet.**

## Assets produced so far (all originated in this repository)

| Asset | Source | License |
|---|---|---|
| `assets/models/maps/test_room/test_room.glb` | Procedurally generated by `tools/blender/generate_test_room.py` (this repo) | Project-owned, no external content |
| `assets/source/blender/test_room.blend` | Same generator | Project-owned |
| All materials in the test room (`M_TestRoom_*`) | Procedural Principled BSDF materials created in the generator script, flat colors only, no external textures | Project-owned |

## Explicitly not yet sourced

- Character models/rigs/animations
- Any of the 20 named paranormal entities
- Any of the 8 named maps' final art (only 1 generic unnamed test room exists)
- Any of the 8 caravans or 8 vehicles
- Any of the 32 equipment items' models
- Any audio (ambient, SFX, voice, music) — no audio hardware in this
  dev container to author/verify against; see `docs/KNOWN_ISSUES.md`
- Fonts, UI icons

When any of the above is sourced from a third party (e.g. a
CC0/royalty-free asset library), it must be added to this table
**before** it is committed to the repository, per the binding rule in
`docs/SOURCE_3D_CONVERSION_PROMPT.md` §17: "İnternetten kullanılan her
ses için: Kaynak bağlantısı, Lisans, Yazar, Değişiklik, Kullanım
koşulu — docs/ASSET_LICENSES.md içinde kaydedilmelidir."
